# 🛒 E-Commerce Sticker Shop – Full Stack Application

A full-stack e-commerce application built using **React.js** and **Spring Boot**, featuring secure authentication, modern UI design, and Stripe payment integration.

---

## 🚀 Tech Stack

### Frontend
- React.js
- Redux Toolkit
- React Router
- Tailwind CSS
- Stripe Checkout

### Backend
- Spring Boot
- Spring Security (JWT Authentication)
- Spring Data JPA & Hibernate
- RESTful APIs
- MySQL
- Stripe Payment Gateway
- Springdoc OpenAPI

---

## ✨ Features

- User registration and login with JWT authentication
- Role-based authorization (Admin / Customer)
- Product listing, search, and cart functionality
- Secure checkout with Stripe payment integration
- Admin dashboard for managing products and orders
- Global state management using Redux Toolkit
- Responsive UI with Tailwind CSS
- Backend validation and exception handling
- API documentation using OpenAPI (Swagger)
